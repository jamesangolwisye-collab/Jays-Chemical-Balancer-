Jay’s Chemical Balancer – Android project

EASIEST (no Android Studio, no installs):
1. Make a free account at github.com and create a new repository.
2. Upload ALL the files in this folder to it (including the hidden .github folder).
   Tip: on the repo page choose "Add file > Upload files" and drag the folder contents in.
3. Open the repository's Actions tab. The "Build APK" job starts by itself (about 3 minutes).
4. Open the finished run and download "JaysChemicalBalancer-apk" under Artifacts. Unzip it to get app-debug.apk.
5. Send app-debug.apk to your phone and open it. Allow "install unknown apps" if asked.

ALTERNATIVE: open this folder in Android Studio and use Build > Build APK(s).

The app works offline and keeps its equation history on the phone.
